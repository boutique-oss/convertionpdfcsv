PDF → CSV Agent

v1.0.0

Outil open-source qui extrait automatiquement les articles d'un catalogue PDF (code, libellé, prix TTC) et génère un fichier CSV tarifaire prêt à l'import, avec calcul du prix de vente HT selon votre taux de marge.

Fonctionnalités :

  • Extraction de texte page par page via PyMuPDF
  • Analyse IA (Claude Sonnet) avec sortie JSON stricte
  • Calcul automatique du PV HT depuis le prix TTC et la marge
  • Interface Gradio — aucun code requis
  • CSV encodé UTF-8 BOM, séparateur point-virgule (compatible Excel)
